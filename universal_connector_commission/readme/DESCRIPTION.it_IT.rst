Agenti e provvigioni per il connettore universale
-------------------------------------------------

Plug-in del connettore universale per il modulo sale_commission.

* La tabella VG7 agents è importata nei soggetti marcati come agente (chiave vg73_id)
* Ordini di vendita: l'agent_id di VG7 imposta il venditore (utente collegato all'agente)
* Ordini di vendita: l'agente VG7 è assegnato al cliente che non ha agente
* Le righe ordine ricevono gli agenti del cliente
* Scheda soggetto: id agente VG7 (vg73_id) nella pagina Sincronizzazione
