Universal Connector plug-in for agents and commissions

Plug-in del connettore universale per agenti e provvigioni

Unknown description_img

Plug-in of Universal Connector for module sale_commission.

  • VG7 table agents is imported into partners flagged as agent (key vg73_id)
  • Sale order: VG7 agent_id sets the salesman (user linked to agent partner)
  • Sale order: VG7 agent is assigned to customer without agent
  • Sale order lines get the agents of customer
  • Partner form: VG7 agent id (vg73_id) in Synchronization page

Plug-in del connettore universale per il modulo sale_commission.

  • La tabella VG7 agents è importata nei soggetti marcati come agente (chiave vg73_id)
  • Ordini di vendita: l'agent_id di VG7 imposta il venditore (utente collegato all'agente)
  • Ordini di vendita: l'agente VG7 è assegnato al cliente che non ha agente
  • Le righe ordine ricevono gli agenti del cliente
  • Scheda soggetto: id agente VG7 (vg73_id) nella pagina Sincronizzazione
