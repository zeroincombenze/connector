This module is a technical module which odoo-client-lib driver.
The PYPI odoo-client-lib package is able to manage both JSONRCP and XMLRPC protocols.
It is an alternative to odoorpc for json connection.
It is a driver for xmlrpc for Odoo 11.0+ (based on python3).
The oerplib was not ported under python3 so it is replace by odoo-client-lib package.
