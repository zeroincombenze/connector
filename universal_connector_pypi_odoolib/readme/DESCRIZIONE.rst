Modulo tecnico per gestire la libreria odoo-client-lib.
La libreria odoo-client-lib può gestire sia JSONRCP che XMLRPC.
Può essere una alternativa a odoorpc per connessioni tramite json.
La libreria gestisce anche xmlrpc per Odoo 11.0+ (basate python3).
La libreria oerplib non è stata migrata verso python3 quindi è rimpiazzata da odoo-client-lib.
