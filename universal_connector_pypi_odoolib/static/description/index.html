odoo-client-lib is a library which manage json and xmlrpc protocols / Protocollo "xmlrpx[s]" per Connettore universale

This module is a technical module which odoo-client-lib driver. The PYPI odoo-client-lib package is able to manage both JSONRCP and XMLRPC protocols. It is an alternative to odoorpc for json connection. It is a driver for xmlrpc for Odoo 11.0+ (based on python3). The oerplib was not ported under python3 so it is replace by odoo-client-lib package.

Modulo tecnico per gestire la libreria odoo-client-lib. La libreria odoo-client-lib può gestire sia JSONRCP che XMLRPC. Può essere una alternativa a odoorpc per connessioni tramite json. La libreria gestisce anche xmlrpc per Odoo 11.0+ (basate python3). La libreria oerplib non è stata migrata verso python3 quindi è rimpiazzata da odoo-client-lib.
