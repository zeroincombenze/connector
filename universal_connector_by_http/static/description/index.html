Add protocol XML-RPC (by requests) to Universal Connector

Aggiunge protocollo XML-RPC (requests) a connettore universale

Unknown description_img

This module enable the importing from remote Odoo instance using XML-RPC. This protocol is another way to use XML-RPC over http/https. It it is implemented by python requests, so the PYPI requests package has to be installed.

You have to use this protocol to connect remote identities different from Odoo.

Questo protocollo è una variante di XML-RPC over http/https. Viene fornito attraverso python requests, quindi il package python PYPI requests deve essere installato.

Usare questo protocollo per identità diverse da Odoo.

Configuration | Configurazione

Settings » Activate the developer mode

Settings » Technical » Synchronization Backend

  1. Set protocol to "By http/https (requests)"
  2. Declare remote user and password (password is not visible)
  3. Or else, insert Client Key rather than password
  4. Declare identity different from Odoo
  5. Choose prefix for this backend
  6. Declare remote user language
  7. Set Endpoint
  8. Click on button Check Connection

If Odoo can connect with remote counterparty, backend state is set to "Ready".

Settings » Activate the developer mode

Settings » Technical » Synchronization Backend

  1. Impostare il protocollo "By http/https (requests)"
  2. Dichiarare nome utente remoto e password (la password non è visibile)
  3. Oppure inserire una Client Key al posto della password
  4. Dichiarare identità diversa da Odoo
  5. Scegliere il prefisso per questa dorsale
  6. Dichiarare la lingua usata da utente remoto
  7. Impostare Endpoint
  8. Fare click su bottone Verificare Connessione

Se Odoo riesce a connettersi con controparte, lo stato della dorsale diventa "Pronto".
