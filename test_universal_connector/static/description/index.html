Tests for Universal connector / Test connettore universale

This module is reserved to internal use of the author to test "Universal connector". Please do not install, it is unusefull for you. However, if you want test "Universal connector" you have to install following Odoo instances on the same server host:

  • Odoo 14.0
  • Odoo 12.0
  • Odoo 10.0
  • Odoo 8.0
  • Odoo 7.0
  • Odoo 6.1

All the DB name must be "test{M}" where {M} is the Odoo major version; i.e. test10 All Odoo instances must use multi-instance rules to run on the same server; please look at https://zeroincombenze-tools.readthedocs.io/en/latest/rtd_description.html#odoo-vid for furthermore information.

Questo modulo è riservato ad uso interno dell'autore per i test del "Connettore universale" Si consiglia di non installare il modulo perché non ha utilità. Qualora si volesse eseguire i test, occorre installare le seguenti istanze di Odoo nello stesso server di questa istanza:

  • Odoo 14.0
  • Odoo 12.0
  • Odoo 10.0
  • Odoo 8.0
  • Odoo 7.0
  • Odoo 6.1

Tutti i nomi dei DB devono essere in formato "test{M}" dove {M} è la versione principale di Odoo; esempio test10 Tutte le istanze di Odoo devono utilizzare alcune regole per essere esguite sullo stesso server; maggiori informazioni sono dispoibili qui:https://zeroincombenze-tools.readthedocs.io/en/latest/rtd_description.html#odoo-vid
