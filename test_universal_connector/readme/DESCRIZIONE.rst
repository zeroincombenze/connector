Questo modulo è riservato ad uso interno dell'autore per i test del "Connettore universale"
Si consiglia di non installare il modulo perché non ha utilità.
Qualora si volesse eseguire i test, occorre installare le seguenti istanze di Odoo
nello stesso server di questa istanza:

* Odoo 14.0
* Odoo 12.0
* Odoo 10.0
* Odoo 8.0
* Odoo 7.0
* Odoo 6.1

Tutti i nomi dei DB devono essere in formato "test{M}" dove {M} è la versione
principale di Odoo; esempio test10

Tutte le istanze di Odoo devono utilizzare alcune regole per essere esguite
sullo stesso server;
maggiori informazioni sono dispoibili qui:https://zeroincombenze-tools.readthedocs.io/en/latest/rtd_description.html#odoo-vid
