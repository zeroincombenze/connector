This module is reserved to internal use of the author to test "Universal connector".
Please do not install, it is unusefull for you.
However, if you want test "Universal connector" you have to install following Odoo instances
on the same server host:

* Odoo 14.0
* Odoo 12.0
* Odoo 10.0
* Odoo 8.0
* Odoo 7.0
* Odoo 6.1

All the DB name must be "test{M}" where {M} is the Odoo major version; i.e. test10
All Odoo instances must use multi-instance rules to run on the same server;
please look at https://zeroincombenze-tools.readthedocs.io/en/latest/rtd_description.html#odoo-vid
for furthermore information.
