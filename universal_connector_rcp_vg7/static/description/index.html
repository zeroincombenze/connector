Add Remote Counterparty VG7 to Universal Connector

Aggiunge gestione controparte VG7

Connector to "VG7 print" software.

This module, based on Universal Connector, allow the download of data from remote "VG7 print" software. Connector can import:

  • Customers
  • Customer addresses
  • Products

Connettore verso software "VG7 print".

Questo modulo, basato su Connettore Universlae, permette di scaricare i dati da "VG7 print". Il connettore può importare:

  • Clienti
  • Indirizzi clienti
  • Prodotti

Configuration | Configurazione

Settings » Activate the developer mode

Settings » Technical » Synchronization Backend

  1. Set protocol to "VG7 Print"
  2. Add Client Key
  3. Declare identity "VG7"
  4. Choose "vg7_id" prefix for this backend
  5. Declare remote user language
  6. Set Endpoint
  7. Click on button Check Connection

If Odoo can connect with remote counterparty, backend state is set to "Ready".

Settings » Activate the developer mode

Settings » Technical » Synchronization Backend

  1. Impostare il protocollo "VG7 Print"
  2. Inserire Client Key
  3. Dichiarare identità "VG7"
  4. Scegliere il prefisso "vg7_id" per questa dorsale
  5. Dichiarare la lingua usata da utente remoto
  6. Impostare Endpoint
  7. Fare click su bottone Verificare Connessione

Se Odoo riesce a connettersi con controparte, lo stato della dorsale diventa "Pronto".
